Part 1.1

For part 1.1, I had to create functions that would execute a convolution of an image using any filter. A convolution is where a filter or a kernel is used to go through each pixel on the image and find the sum of the dot product between the kernel and a matrix of the same size on the image centered on the given pixel. Therefore, to code a convolution, I would need to iterate through all the pixels on the image and apply the filter to it.
All images were converted to greyscale before applying the convolution.

Padding

For my four and two loop functions, I created padding using np.pad(). The padding for each dimension was the size of half of the kernel. This is because the convolution centers the kernel on the pixel and calculates the dot product of this. Therefore, I needed to add padding for half the kernel for the edges. Below is a drawing I made to show an example of what I'm referring to.

Four Loop Function

In my four loop function, it first will flip the filter in the x-direction and y-direction. This is because when doing a convolution, you need to flip the filter in both the x- and y-direction. It's important to flip the filter since I will be using this function for the finite difference filters which are not symmetrical.
Afterwards, I loop through each (x, y) coordinate of the image. At each (x, y) coordinate, I iterate through each (i, j) coordinate of the kernel and multiply the kernel value with the value in the corresponding coordinate in the image (i.e. kernel[i, j] * matrix[x+i, y+j]. These values are all added together and averaged to become the new value for the (x, y) coordinate. The reason I can do x+i and y+j is because of my padding. I am iterating through the padded image from 0 which corresponds to the padding.

Initial Function

The task for this part was to create code that could sharpen an image using a Gaussian filter. To sharpen the images, I needed to magnify the existing high frequencies in the image. I did this by doing a convolution of the image with the gaussian filter which blurs the image and removes high frequencies. Then, I subtracted the blurred image from the original image to obtain a matrix of the high frequencies of the image. I added the matrix of high frequencies to the original image to sharpen the image. In addition, I multiplied the matrix of high frequencies by 1.1 (alpha) to increase the magnitude of the high frequencies, further sharpening the image. Combining into One Convolution

I also combined the steps together using the following unsharp mask filter formula that was introduced during lecture 6: (1 + alpha) * unit_impulse - alpha * gaussian filter.
The unit impulse is a kernel with 1 in the center and 0 around it to represent the original image's pixel. This is because to sharpen the image you need image - (image - blurred image) * alpha. The alpha is how much I multiply the matrix of high frequencies to adjust the sharpness of the image. The unit impulse is why I needed to make the kernel size 6 * sigma + 1, as this will ensure that the kernel is always odd so that there is a center of the kernel.

Part 2.2

To create the hybrid images, I needed to combine an image with high frequencies and another with lower frequencies. The higher frequencies have more detail that can be seen up close, and the lower frequency image will be visible from further away as the human eye aliases the high frequencies away. For this task, I stuck to using just the greyscale version of the images.

Align Images

To align the images, I used the starter code provided. The coordinates I selected on the images to align them are listed in my results section.

Low Frequency Filter Pass

For my low frequency filter, I created a gaussian filter and convolved the 'low-pass' images with the gaussian filter. Blurring with a gaussian filter removes the high frequency details, leaving only the lower frequency details. The kernel size of the gaussian filter was 6 * sigma.

High Frequency Filter Pass

For my high frequency filter, I created another gaussian filter separately from the low frequency filter. I decided to do this because when I initially used the same gaussian filter for both passes, I found that the results either left too much high frequencies in the low pass image or too little high frequencies in the high pass image. Therefore, having two separate filters for the low and high frequency filter passes allowed me to adjust each image separately. The kernel size of the gaussian filter was also 6 * sigma.

To get the high frequency image, I convolved the 'high-pass' images with the gaussian filter and then subtracted this result from the original image. Since the gaussian filter only keeps lower frequencies, subtracting the result from the original image will only keep the higher frequencies. For one of the hybrid images I also sometimes used an alpha value > 1 to magnify the high frequencies of the 'high-pass' images to make it more visible.

Part 2.3 and 2.4

Gaussian and Laplacian Stacks

To blend the images together, I needed to implement gaussian and laplacian stacks. In the paper, they implemented laplacian stacks of levels 0, 2 and 4. To do this, I iteratively convolved the two images with a gaussian filter of sigmas from 0 to 4 to generate blurred images. Then each laplacian stack was created by subtracting the convolved images from each other. Here is the full breakdown of how my code created the laplacian levels:

  1. Laplacian Image at level 0: original_image - image_gaussian_2, where image_gaussian_2 was the result of convolving the original_image with a gaussian filter of sigma 2
  2. Laplacian Image at level 2: image_gaussian_2 - image_gaussian_4, where image_gaussian_4 was the result of convolving the image_gaussian_2 with a gaussian filter of sigma 4
  3. Laplacian Image at level 4: image_gaussian_4, this is because I only generated gaussian filters of sigmas 0, 2 and 4 since there are only 4 levels. So the last laplacian level will simply be the convolved image with a gaussian filter of sigma=4. This will ensure the lower frequencies are added back into the image when I combine the laplacian stack, as those are eliminated at levels 0 and 2

Afterwards, to create images j-l, my program added the laplacian levels together.

Multiresolution blending for Laplacian Stacks

I blended each image to remove the seam by using a gaussian filter on the mask. At each laplacian level, I convolved the previous level's mask with a gaussian filter. The gaussian filter's sigma was m * (the level number), where m is a variable that can be changed. This was because a sigma of 2 and 4 created too little blurring in the seam, and so I needed to have a larger kernel and sigma in order to create a smoother transition from 0 to 1 in the mask. To do the multi-resolution blending, I combined the two images using the blurred mask using the equation we learnt in lecture: left_image * (1-mask) + right_image * mask
To get the individually masked images like on the right and middle columns of the example, I just multiplied the left image with (1 - mask) and the right image with (mask)
